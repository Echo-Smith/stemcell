# Agent 编辑部演示页

这是基于当前《莫思意｜模型应用产品经理（AI Memory & Agent）》定向简历实现的本地交互演示。页面不依赖后端、数据库、模型 API 或在线字体。

## 本地运行

在项目根目录执行：

    python3 -m http.server 4173

然后打开：

    http://127.0.0.1:4173/agent-editorial-demo/

也可以直接双击 index.html；使用本地 HTTP 服务时，页面底部的简历文字稿与 PDF 相对链接更稳定。

## 演示顺序

1. 点击“运行协作流”，观察研究、写作、审校 Agent 的版本化接力。
2. 点击四个 Memory 层，查看各自作用范围、当前生效内容与治理字段。
3. 在 Decision Packet 中分别体验“批准并进入待发布”“退回写作 Agent”“我来接管”。每次更换路径前点击“重置演示”。
4. 接管路径会打开本地人工修改区；内容只保存在当前页面状态，不会上传。

## 事实边界

- 用户数、任务样本、批量任务结果来自 resume/current/莫思意-AI Memory&Agent-模型应用产品经理-文字稿.md。
- 四层 Memory、三 Agent 编排、Lease、动态质量路由和 Decision Packet 的机制来自同一简历及 resume/evidence/2026-08-04-笔润智谈V2架构实现核验.md。
- “公共事件评论稿”是用于解释交互的机制样例，不是线上日志或用户案例。
- 页面未添加转化率、准确率、线上稳定性、监控收益等未被证实的指标。
