# 测试产物快照

仅用于 test / 实验复查。所有需求均为模拟材料；未填入人工偏好，也没有生产验证。

- `live-pilot/`：一个模拟需求的真实模型调用记录、三组方案、匿名材料与空白人工记录。生成和裁判使用同一模型。
- `offline/`：十案例协议模拟的报告、匿名占位材料与汇总，不能用于评价方案质量。
- `private/` 是实验工具沿用的目录名，用于隔离方法映射与评分以减少盲评提示。本次随仓库公开的内容仅含模拟需求和测试输出，不是保密数据；盲评前不要查看映射。

未收录 API 密钥、环境文件或供应商连接地址。快照不随代码自动重跑；比较新的运行时应保留模型、并发、输出预算和数据来源。输出中的操作步骤仍可能错误，已知 Git 恢复漏检见上级实验结论。
