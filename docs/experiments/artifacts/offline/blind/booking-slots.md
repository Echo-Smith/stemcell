# booking-slots / 预约时段管理

材料类型：synthetic。

离线协议模拟，不能评估方案质量。

## 原始需求

为个人工作室提供预约时段展示与预订，初期每天不超过二十次预约。
硬约束：同一个时段不能被重复预订。
硬约束：第一版不接入支付。
硬约束：管理者必须可以手动关闭时段。
未知：是否需要跨时区；首版服务本地用户。

各组展示相同字段；不展示方法、模型评分和调用开销。内容风格仍可能泄露方法，不能保证完全盲法。
