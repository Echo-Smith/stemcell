# csv-import / CSV 数据导入

材料类型：synthetic。

离线协议模拟，不能评估方案质量。

## 原始需求

为个人收支记录应用增加 CSV 导入，用户主要来自不同银行导出的文件。
硬约束：必须支持导入前预览。
硬约束：重复导入不得重复记账。
硬约束：不得将账单内容发送给外部模型。
未知：所有银行格式。需要解释格式不支持时如何处理。

各组展示相同字段；不展示方法、模型评分和调用开销。内容风格仍可能泄露方法，不能保证完全盲法。
