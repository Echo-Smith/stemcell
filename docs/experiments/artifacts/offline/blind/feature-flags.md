# feature-flags / 小应用功能开关

材料类型：synthetic。

离线协议模拟，不能评估方案质量。

## 原始需求

为一个开发者维护的应用加入实验功能开关，逐步邀请部分用户体验。
硬约束：关闭实验功能后核心功能仍须可用。
硬约束：不得在客户端保存管理员凭据。
硬约束：首版不需要统计显著性检验。
背景：用户量小，需支持紧急关闭；未知：现有身份体系。

各组展示相同字段；不展示方法、模型评分和调用开销。内容风格仍可能泄露方法，不能保证完全盲法。
