# feedback-inbox / 用户反馈收件箱

材料类型：synthetic。

离线协议模拟，不能评估方案质量。

## 原始需求

给一个已有 200 位试用用户的小工具增加反馈入口，便于归类和追踪。
硬约束：两周内交付首版。
硬约束：不得要求用户注册新账号。
硬约束：首版不自动回复用户。
偏好：容易导出数据，后续可能邀请第二个维护者。

各组展示相同字段；不展示方法、模型评分和调用开销。内容风格仍可能泄露方法，不能保证完全盲法。
