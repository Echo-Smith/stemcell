# image-compress / 浏览器图片压缩

材料类型：synthetic。

离线协议模拟，不能评估方案质量。

## 原始需求

为个人博客作者增加图片压缩和批量打包下载功能。
硬约束：图片原始文件不得离开浏览器。
硬约束：用户必须能比较压缩前后效果。
硬约束：第一版只处理 JPEG 和 PNG。
偏好：打开即用，不要求登录。

各组展示相同字段；不展示方法、模型评分和调用开销。内容风格仍可能泄露方法，不能保证完全盲法。
