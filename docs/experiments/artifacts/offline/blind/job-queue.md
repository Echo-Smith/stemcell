# job-queue / 后台任务状态

材料类型：synthetic。

离线协议模拟，不能评估方案质量。

## 原始需求

现有小应用的报告生成耗时较长，希望让用户离开页面后仍能查看进度。
硬约束：任务失败必须显示可理解的原因。
硬约束：同一请求的重试不得重复生成收费任务。
硬约束：第一版只支持单个服务实例。
未知：服务重启后的恢复要求，需要指出取舍。

各组展示相同字段；不展示方法、模型评分和调用开销。内容风格仍可能泄露方法，不能保证完全盲法。
