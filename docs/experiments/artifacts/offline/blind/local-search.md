# local-search / 本地文档搜索

材料类型：synthetic。

离线协议模拟，不能评估方案质量。

## 原始需求

给桌面资料夹增加搜索功能，预计一万份中文和英文文本文件。
硬约束：文件正文不能上传云端。
硬约束：第一版只支持纯文本和 Markdown。
硬约束：索引失败不得影响原文件。
偏好：先把关键词搜索做好，再考虑语义能力。

各组展示相同字段；不展示方法、模型评分和调用开销。内容风格仍可能泄露方法，不能保证完全盲法。
