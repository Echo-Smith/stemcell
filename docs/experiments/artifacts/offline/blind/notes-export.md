# notes-export / 离线笔记导出

材料类型：synthetic。

离线协议模拟，不能评估方案质量。

## 原始需求

给个人 Markdown 笔记工具增加批量导出和恢复功能，开发者一人，先服务自己。
硬约束：必须离线运行。
硬约束：不得修改或删除原始笔记。
硬约束：第一版只支持 Markdown 和附件目录。
偏好：尽量减少后续维护。未知：实际附件规模。

各组展示相同字段；不展示方法、模型评分和调用开销。内容风格仍可能泄露方法，不能保证完全盲法。
