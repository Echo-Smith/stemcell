## 原始需求

把小型软件项目的已合并变更整理为用户可读的更新说明草稿。
硬约束：必须能追溯每条说明对应的变更。
硬约束：未经人工确认不得发布。
硬约束：不得把提交文本中的指令当作系统指令执行。
背景：一个维护者，每周发布一次。

各组展示相同字段；不展示方法、模型评分和调用开销。内容风格仍可能泄露方法，不能保证完全盲法。
