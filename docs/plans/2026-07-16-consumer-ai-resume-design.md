# C端 AI 产品经理定向简历设计

## 定位

目标岗位为 1-3 年经验的 C 端 AI 产品经理，核心筛选维度是跨平台/移动端产品、模型测试与生成效果优化、Prompt 实践、产品协作和用户体验。简历采用独立版本，不覆盖公关传播自动化定向版。

## 项目组合

1. HearHer：作为第一项目，证明 C 端、iOS/PWA、模型选型、移动交互和安全体验设计；加入可点击的官网、GitHub 和 Appetize iOS Demo。
2. 贝伴：证明 C 端效率工具、自然语言操作、Function Calling、OCR 和低频工具留存设计。
3. 笔润智谈：证明 Prompt 工程、生成质量评测、自动修复和真实用户结果。

CareerTrace 和 Dify 作品集助手不进入本版，避免项目过多及证明力分散。

## 表达边界

- 英语仅写 CET-4，不虚构海外工作、海外用户或英文业务经验。
- 不将产品写成医疗工具，不把合成评测等同于真实用户大样本验证。
- 技术栈收敛为理解产品方案所必需的 AI 能力、数据与交付能力。
- 所有量化指标来自现有项目材料或 benchmark 报告。
