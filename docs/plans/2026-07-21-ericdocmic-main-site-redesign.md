# ericdocmic.top 主站改版设计

## 目标

把 `ericdocmic.top` 从个人项目入口索引改为单一的中文主站页面「eric的开发日记」。页面不出现 GitHub、作品集、简历或项目入口信息，不保留左上角图形标志，并为不存在的访问路径提供同风格的 404 页面。

## 视觉方向

采用“便签纸手账”方向。它比像素终端更亲切，也比传统日历更适合作为长期可更新的开发日记载体。页面使用奶白纸张、墨蓝文字、草莓粉、嫩芽绿与阳光黄，避免常见的科技蓝紫渐变。标题采用带手写感的中文楷体字族，正文采用清晰的无衬线字族，日期与状态使用等宽字体。

页面的唯一视觉记忆点是一张带轻微倾斜、虚线装订边和折角的“今日手记”。其余区域保持安静，避免堆叠卡片、阴影和装饰。进入页面时仅有一次轻微上浮动画；用户启用减少动态效果时完全停用动画。

## 页面结构

主页面由文字站名、简短状态、主标题、说明文字、“今日手记”和页脚组成。所有内容都留在当前页面，不提供站外导航。手记内容描述持续记录开发过程的意图，不虚构具体项目或成果。

404 页面复用颜色、排版和纸张语言，以醒目的 `404`、明确说明和“回到开发日记”按钮引导用户返回根路径。部署包同时包含 `index.html` 与 `404.html`，以适配静态网站服务器的错误页配置。

## 验收

- 主页面不含 GitHub、作品集、简历或具体项目链接与文案。
- 左上角只有文本站名，没有图形标志。
- 桌面与 320px 以上移动端布局完整。
- 键盘焦点清晰，尊重 `prefers-reduced-motion`。
- 404 页面能够独立打开并返回 `/`。
- 1Panel 导出包包含 `index.html` 和 `404.html`。
