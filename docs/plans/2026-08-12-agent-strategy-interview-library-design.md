# Agent 策略岗位面试库设计

## 目标

基于既有小红书电话准备稿、投递简历、岗位 JD 和 2026-08-12 真实业务面，建立可复用的 Agent 策略岗位面试复盘与标准回答库。

## 信息架构

采用三层结构：

1. **事实复盘层：**记录面试题序、考察意图、候选人表现和真实能力边界；会议助手的主观评价不作为面试官结论。
2. **标准回答层：**按业务、Agent 原理、检索、Eval、Badcase、Prompt、Memory、协作和压力题组织答案；每题同时给出短答、展开逻辑、追问和禁区。
3. **临场训练层：**压缩为面试前十分钟速记卡，使用“结论—场景—机制—证据—边界”回答结构，避免开场卡顿和被追问后临时拼接口径。

## 事实原则

- “笔润智谈”是项目标准名称。
- 2026 年 5—8 月，14 位作者借助产品完成 28 篇获栏目刊发的稿件；单个用户最高使用 20 余次；200+ 为体验补充规模。
- 不声称提升投稿成功率，因为缺少投稿分母和可比基线。
- 当前真实工作流的质量判断以人工评估为主；代码中存在评测结构与离线原型，不等于生产级自动化 Eval Loop。
- 部门采纳并拆分部署的是“核查较真”能力，不表述为整个个人产品完成公司级部署。
- V2 代码实现、离线验证、真实用户使用和部门内部应用分别陈述，不互相替代。
