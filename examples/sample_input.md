# 示例输入：个人项目想法

我想做一个面向独立开发者的 Agent 工具，核心思路是把用户的原始想法（笔记、聊天记录、需求文档）输入进去，系统自动提炼出一个通用的"底座"，然后基于这个底座批量生成多个不同视角的候选方案，再自动打分筛选出最好的几个。

技术上希望尽量轻量，不要依赖复杂的 Agent 框架，最好就是纯提示词编排 + API 调用。用户群体是像我这样的独立开发者和创作者，他们经常需要在多个方案之间做选择，但又不想自己一个个去试。

约束条件：
1. 必须是开源的，MIT 协议
2. 优先做 CLI 工具，后续再考虑 GUI
3. 支持自定义视角和打分维度
4. token 消耗要可控，不能一跑就爆

我现在的痛点是：每次想一个方案，都要自己跟 AI 反复对话，换不同的角度去问，然后自己对比筛选，非常费 token 也费时间。希望这个工具能把这个过程自动化。

风格偏好：简洁、直接、不废话，输出要结构化。
