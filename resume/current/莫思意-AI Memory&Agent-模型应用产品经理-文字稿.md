## 核心项目

### 笔润智谈｜面向内容生产的 Memory & Agent 协作产品　2026.03—至今

个人发起并独立构建｜V1 已进入内部内容生产流程，V2 内测中  
luminbuddy.ericdocmic.top｜github.com/Echo-Smith/luminbuddy-writing-agent-v2

- **从真实场景定义问题：**面向时评作者、编辑与日常内容运营场景，发现写作规范难复用、热点资料分散，以及生成后资料核验、个人视角缺失、版本追踪和返工协作耗时等问题；先以 V1 验证写作、润色和批量查重需求，再将产品演进为可追踪、可回退、可人工接管的 Agent 编辑部。
- **设计四层 Memory 产品边界：**用户对公共事件标题、数字使用和个人视角的反馈存在差异，单次意见不适合写入全局 Prompt；因此以工作摘要、会话消息、长期偏好和实体关系网络组成四层记忆，按用户、来源、适用范围、置信度和生命周期治理，并提供 Markdown 与数据库导入 / 导出，使偏好可查看、可修正、可迁移。
- **平衡确定性与 Agent 自主性：**将内容任务拆为意图识别、查询规划、多源检索、提纲确认、生成和审校修复等工具；保留固定 Pipeline 保障关键步骤顺序，以 ReAct UnifiedAgent 按状态选择工具，统一设置取消、全局超时、Token 预算、断连暂停和连续 LLM 失败断路器，并以迭代上限和人工确认超时避免无限等待。
- **编排可接管的 Agent 编辑部：**将研究、写作、审校三类 Agent 编排为版本化协作流，以数据库 Lease 防止重复执行，按信源、信息缺口、稿件结构和审校严重度动态路由；设计 Decision Packet 汇总建议、依据、不确定性和批准后果，低质量任务有限重试后进入人工批准、退回或接管。
- **用反馈推动版本迭代：**V1 累计覆盖 200+ 名体验用户，其中 53 名作者均完成真实写作任务；根据格式同质化反馈调整写作规范并禁用模板化句式，根据价值取向差异引入个性化记忆。V2 截至 2026.07.31 已有 14 名用户、近 70 条完整任务样本。
- **验证稳定交付：**针对集中投稿期查重效率低、失败率高的问题重构并发与失败兜底，完成 30 余次批量任务；单次处理 50 余人、每人 30 条语录文本，5 分钟内全部改写返回。
