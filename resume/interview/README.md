## 使用顺序

1. 新岗位到来后，先用主库检查岗位的能力模块；
2. 根据 JD 选择 15—20 个问题制作定向题单；
3. 每个答案按“结论—场景—机制—证据—边界”组织；
4. 面试前使用速记卡，不在临场继续扩充技术术语；
5. 面试结束后更新结果复盘，并把新证据或口径修正写入证据台账。
